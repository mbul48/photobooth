# PhotoBooth

A React-based web application for creating photo strips with various effects and shapes.

## Features

- Take photos using your device's camera
- Upload existing photos
- Apply different visual effects
- Choose from various photo shapes
- Download your photo strips

## Installation

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```

## Technologies Used

- React
- TypeScript
- Lucide React (for icons)
- HTML5 Canvas API
